# Manqing Fu's GitHub Pages

This repository hosts my personal GitHub Pages site, which is built using Docsify. The site serves as a platform for sharing knowledge and resources related to Reinforcement Learning and Control Theory.

# How to Run the Site Locally

To run this site locally, you need to have [Docsify](https://docsify.js.org/) installed. You can install it via npm if you haven't done so already:

```bash
npm install -g docsify-cli
```

Please run docsify serve .
